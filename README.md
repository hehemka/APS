# Центр антивирусной проверки файлов

**Практическая работа по архитектуре вычислительных систем**  
Храмцова Дарья 5130904/40102 вариант 12

Моделируется очередь заданий на проверку файлов. Запросы поступают от рабочих станций, файловых шлюзов и серверных приложений. Сканирующие процессы обрабатывают по одному файлу. Когда они заняты, задания ждут в буфере; если свободных мест не осталось, срабатывает правило вытеснения.

**Вариант:** `ИБ ИЗ2 ПЗ1 Д1ОЗ3 Д1ОО4 Д2П2 Д2Б3 ОР1 ОД3`

| Код | Что происходит |
|:--|:--|
| ИБ | Источники генерируют новые задания без ограничения количества |
| ИЗ2 | Интервалы между заявками равномерно распределены |
| ПЗ1 | Продолжительность проверки имеет экспоненциальное распределение |
| Д1ОЗ3 | Задание занимает первый свободный слот, остальные не сдвигаются |
| Д1ОО4 | При полном буфере вытесняется последняя попавшая в него заявка |
| Д2Б3 | Задание выбирается обходом занятых слотов по кольцу |
| Д2П2 | Свободный сканер ищется по кольцу |
| ОР1 | В конце выводится сводная таблица статистики |
| ОД3 | В пошаговом режиме предусмотрено отображение динамики событий |

**Основной сценарий:** поступление задания, переполнение буфера, освобождение сканера и передача на проверку.

При одновременных событиях сначала завершается обслуживание, затем обрабатываются новые поступления. Если несколько заданий имеют одинаковое время размещения, при вытеснении выбирается записанное позже (по порядковому номеру записи). На новое поступление диспетчер сначала помещает заявку в буфер, затем при наличии свободного сканера запускает выбор из очереди: поэтому кольцевой порядок выбора сохраняется и при свободном сканере.
